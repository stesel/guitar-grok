# 2NPS Picking — Fast String Changes Without Getting Trapped

**Goal:** Build clean, relaxed string transitions for two-notes-per-string (2NPS) licks using efficient alternate picking and short speed bursts.

2NPS patterns often feel harder than 3NPS patterns even when your raw picking speed is already good. The reason is simple: you must cross a string after only two notes, so inefficient pick movement is exposed immediately.

## Setup

- Standard tuning or your normal practice tuning
- Clean or lightly distorted tone
- Metronome
- Start around 80–100 BPM with sixteenth notes
- Use strict alternate picking unless an exercise says otherwise

Picking notation:

```text
D = downstroke
U = upstroke
```

## Core idea — Escape the string cleanly

For an ascending 2NPS pattern starting with a downstroke:

```text
e|----------------5-8-
B|------------5-8-----
G|--------5-7---------
D|----5-7-------------
A|5-7-----------------
   D U D U D U D U D U
```

Every string change happens after an **upstroke**.

The important movement is:

```text
Downstroke  → through the string
Upstroke    ↗ slightly away from the guitar
```

The upstroke does not need a large jump. It only needs enough clearance to move to the next string without the pick becoming trapped between two strings.

Do not deliberately make a large semicircle. The motion should stay small and relaxed.

## Exercise 1 — Muted String Crossing

Remove the fretting hand from the problem.

Lightly mute two adjacent strings and alternate between them:

```text
B|----x-x----x-x----x-x----x-x-
G|x-x----x-x----x-x----x-x-----
   D U D U D U D U D U D U D U
```

Think in groups of two:

```text
D U | D U | D U | D U
```

### Focus

- very small pick movement
- relaxed wrist and forearm
- no visible jump over the string
- after each `U`, the pick should already be free to move to the next string

Play for **30–45 seconds**, rest, then repeat 3 times.

## Exercise 2 — Four-Note 2NPS Burst

Use only two strings:

```text
B|------5-8-
G|--5-7-----
   D U D U
```

Play the four notes quickly, then stop completely.

```text
PLAY — REST — PLAY — REST
```

Do not try to sustain the lick for a full bar yet.

### Focus

The critical movement is the transition:

```text
G string: U
          ↓ string change
B string: D
```

The first note on the B string should feel like the natural continuation of the previous upstroke, not a separate jump.

Do **8–10 bursts**, resting briefly between each one.

If the burst is clean, test it slightly faster rather than immediately increasing the length.

## Exercise 3 — Continuous Two-String Loop

Now connect the bursts:

```text
B|------5-8------5-8------5-8------5-8-
G|--5-7------5-7------5-7------5-7-----
   D U D U D U D U D U D U D U D U
```

Start at a tempo where you can play the pattern for 20–30 seconds without tension.

### Tempo method

1. Start around **80–100 BPM**, sixteenth notes.
2. Increase by **5 BPM** only after 3 clean repetitions.
3. Occasionally test a much faster tempo for only one short burst.
4. Return to your controlled tempo afterward.

The goal is not to force a slow movement to become fast. The goal is to discover the smaller movement that already works at speed.

## Exercise 4 — Full 2NPS Ascending Run

Extend the same movement across five strings:

```text
e|----------------5-8-
B|------------5-8-----
G|--------5-7---------
D|----5-7-------------
A|5-7-----------------
   D U D U D U D U D U
```

Play it first as separate groups:

```text
A string: D U
D string: D U
G string: D U
B string: D U
e string: D U
```

Then connect the complete run.

### Focus

Do not concentrate on the fretting hand unless it is causing a real mistake.

Listen specifically to the **first note of every new string**. If those notes are late, weak, or accented accidentally, the string crossing is probably still inefficient.

Repeat the run **5 times cleanly** before increasing the tempo.

## Exercise 5 — Direction Change Challenge

Ascending and descending string changes are not mechanically identical. Practice the turnaround separately.

```text
e|------------5-8-8-5------------
B|--------5-8---------8-5--------
G|----5-7-----------------7-5----
D|5-7-------------------------7-5
```

Use strict alternate picking throughout.

Start slowly enough to identify exactly where the turnaround becomes uncomfortable.

Then isolate only that area, for example:

```text
e|----5-8-8-5----
B|5-8---------8-5
```

### Focus

- stay relaxed at the top of the lick
- do not make a larger pick motion just because the direction changes
- listen for unwanted pauses between strings
- keep the pick close to the string plane

Practice the turnaround as **4–8 note bursts** before attempting long repetitions.

## Optional — Compare Economy Picking

Strict alternate picking is an important skill, but it is not mandatory for every musical lick.

Take one of the exercises above and experiment with economy picking so that a string change can sometimes continue in the same pick direction.

Compare:

- strict alternate picking
- economy picking

Do not choose based only on which one feels faster once. Choose the technique that remains clean, synchronized, and relaxed when repeated.

## Common Problems

### The pick feels trapped

Your final stroke on the string is probably staying too parallel to the guitar body.

Use a very small escape movement rather than adding a large hopping motion.

### The first note on every new string is late

Practice Exercise 2. Your raw picking speed is probably not the limitation — the transition is.

### You tense up only at high speed

Use short bursts. Stop before tension accumulates.

### 3NPS feels easy but 2NPS feels impossible

That is normal. In 3NPS patterns, the picking direction changes relative to the string transition. In 2NPS patterns, the same type of crossing repeats constantly, so weaknesses in your escape motion become much more obvious.

# 10-Minute Practice Routine

```text
2 min — Exercise 1: muted crossings
2 min — Exercise 2: four-note bursts
2 min — Exercise 3: continuous two-string loop
2 min — Exercise 4: full ascending run
2 min — Exercise 5: direction changes
```

Record your fastest **clean and relaxed** tempo for Exercises 3–5.

Do not record a tempo if you can only play it once with tension.

# Homework

Practice the routine for at least **5 sessions**.

At the end of each session, write down:

1. Clean continuous tempo for Exercise 3.
2. Clean tempo for the full ascending run.
3. Clean tempo for the direction-change exercise.
4. Which specific string transition feels hardest.
5. Whether the problem feels like picking, fretting-hand synchronization, or both.

Then create one short **2NPS metal lick** of your own using at least three strings.

Keep it to 8–16 notes and write the picking directions underneath the tab before practicing it at speed.
